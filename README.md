A personal portfolio website built using semantic HTML5 to demonstrate modern web development practices and accessibility standards. The website includes dedicated sections for Home, About, Skills, Projects, and Contact. It uses semantic elements such as header, nav, main, section, article, and footer to create a meaningful document structure. Accessibility features include descriptive alt text, properly associated form labels, keyboard navigation, and appropriate ARIA attributes where necessary. SEO-friendly meta tags and descriptive page titles improve search engine visibility. This project focuses on writing clean, maintainable HTML while establishing a strong foundation for responsive design and future interactive features.
